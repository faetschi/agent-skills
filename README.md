# agent-skills

A compact, practical collection of personal skills, commands, hooks, workflows, and plugins for Claude, Cline, GitHub Copilot, OpenCode, and other AI tooling.

- **What’s inside:** reusable skills, CLI commands, editor hooks, CI/workflows, and model/plugin integrations.
- **How to use:** browse folders, copy or import items, and follow each item's usage notes.

**Features**

- Small, focused automations and prompt/skill templates.
- Editor integrations and CI workflows you can reuse or adapt.
- Examples and quick snippets to get started fast.

**Quickstart**

1. Explore the repository structure and folders.
2. See each folder for concrete examples and usage notes
3. Copy, adapt, or import the pieces into your project.
